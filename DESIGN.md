# DESIGN.md

## Karakter Visual
Minimalis, fungsional, tegas, zero-noise, penekanan pada matriks rekomendasi dan hierarki informasi transparan.

## Tipografi
Sans-serif modern (Geist / Inter), kontras tinggi, penomoran tabular untuk matriks skor dan bobot.

## Palet Warna
Netral gelap/terang, aksen fungsional berorientasi status (hijau untuk kecocokan tinggi, kuning untuk peringatan beban, merah untuk pelanggaran hard constraint).

## Token Jarak & Gerak
Spacing grid 4px/8px, transisi halus standar tanpa animasi berlebih.

## Kerapatan Tabel & Matriks
Padat informatif, baris dapat dipindai cepat, indikator komponen skor (K, S, C, M) jelas per sel.

## Kondisi UI
- Loading: Skeleton ringkas.
- Empty State: Panduan tindakan awal eksplisit.
- Error: Pesan error spesifik, tanpa menyembunyikan detail teknis yang aman.

## Aksesibilitas
Kontras warna minimum WCAG AA, navigasi keyboard penuh untuk form dan matriks.
